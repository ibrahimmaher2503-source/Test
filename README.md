# Launchpad

مشروع تجريبي بسيط — صفحة ساكنة (HTML/CSS/JS) من غير أي build step، جاهزة للنشر
مباشرة على [Vercel](https://vercel.com).

## تشغيل محلي

افتح `index.html` في المتصفح مباشرة، أو شغّل سيرفر بسيط:

```bash
npx serve .
```

## النشر على Vercel

المشروع static بالكامل، فمفيش أي إعدادات build مطلوبة — استورد الريبو في Vercel
وهيتنشر تلقائيًا.
