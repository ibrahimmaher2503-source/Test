# Product Requirements Document (PRD)

# Barcode Inventory System

## Purpose

A lightweight web-based inventory counting system using mobile barcode
scanning.

## Goals

-   Fast inventory
-   Mobile scanning
-   Multi-branch support
-   CSV export

## Scope

### Included

-   Branchs
-   Users
-   Products
-   Inventory sessions
-   Barcode scanning
-   Reports

### Out of Scope

-   POS
-   Sales
-   Accounting
